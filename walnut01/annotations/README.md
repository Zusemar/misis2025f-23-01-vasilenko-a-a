# Разметка КТ-сечений грецкого ореха, версия 0.1

Размечены все 12 исходных сечений 501 × 501 пиксель. Это полуавтоматическая
разметка, подготовленная агентом: принадлежность областей выбрана по исходным
снимкам, границы уточнены с помощью интенсивности, затем проверены визуально.
Это не независимая экспертная разметка. Рабочий алгоритм сегментации проекта
на этом этапе не разрабатывался и не оценивался.

## Классы

| Значение в маске | Класс | Цвет просмотра |
|---|---|---|
| 0 | Воздух / фон: внешняя среда, внутренние пустоты, держатель и фоновые артефакты | `#111827` |
| 1 | Скорлупа и различимые внутренние стенки / перегородки | `#F2AD48` |
| 2 | Видимые сечения ткани ядра, включая небольшие изолированные фрагменты | `#38BDF8` |

Включение перегородок в класс 1 — операционное правило разметки, а не
утверждение о гистологическом составе каждой перегородки.

## Файлы

- `../data/images/`: исходные TIFF float32 без изменения значений; совпадение
  с файлами преподавателя проверено по Git blob SHA-1. SHA-256 исходников
  сохранены в `manifest.json`.
- `masks/`: одноканальные PNG uint8 со значениями **0, 1, 2**, без цветовой
  палитры и без изменения исходной геометрии.
- `previews/*_pair.png`: исходный снимок слева, цветная маска справа.
- `previews/overview_01.png` … `overview_03.png`: все 12 пар на трёх листах.
- `overlays/`: наложение маски на исходник для проверки совпадения границ.
- `uncertainty/`: отдельные бинарные PNG, 255 — полоса около границы классов,
  требующая осторожной интерпретации, 0 — вне этой полосы. Это эвристическая
  полоса, а не статистическая вероятность ошибки; семантически спорные области
  она может не охватывать.
- `annotation_spec.json`: выбранные агентом точки в областях ядра, огибающие
  полигоны, исправляющие штрихи перегородок и параметры вспомогательной обработки.
- `prepare_annotations.py`: воспроизведение этой версии разметки и иллюстраций
  по зафиксированным входным указаниям агента; не метод автоматического
  распознавания новых изображений.

Исходники для просмотра отображаются с общим окном интенсивности `[0, 0.067]`.
Это не изменяет TIFF. Отдельные более яркие пиксели на иллюстрации насыщаются.
Маски сохраняются без сглаживания и JPEG-сжатия.

Сечения `1430` и `2430` размечены целиком как фон: видны держатель и текстура
реконструкции, ткань ореха не различима. На сечении `0430` выделена скорлупа
с перегородками, уверенно различимого ядра нет.

## Происхождение

Данные: [выборка преподавателя](https://github.com/dvpsun/misis2025f-23-00-polevoi-d-v/tree/5e7d4a2d3b07244be972243acca1a6f6a8ccc2b9/data/walnut01).
Статья: [Der Sarkissian et al., Scientific Data, 2019](https://doi.org/10.1038/s41597-019-0235-y).

Старые JPEG/PNG из `walnut01/` заменены исходными TIFF в `data/images/`:
некоторые старые конвертации теряли контраст. Старые автоматически созданные
`ground_truth` из `prj.lab/lab04` просмотрены, но не использовались как эталон
или как вход для построения новых масок. Прежние лабораторные не изменены.

## Воспроизведение

Нужны Python, NumPy, Pillow, SciPy и OpenCV:

```sh
python -m pip install -r walnut01/annotations/requirements.txt
python walnut01/annotations/prepare_annotations.py
```

Маски предназначены для первоначального просмотра и дальнейшей проверки.
При последующей оценке методов необходимо указывать происхождение разметки,
отдельно рассматривать неоднозначные границы и не использовать эти же
вспомогательные правила как независимый эталон для их собственной проверки.
