# Итоговый отчёт по проекту

`walnut_project_report.pdf` — версия для чтения и печати.
`walnut_project_report.docx` — редактируемый исходник с нативными формулами Word.

Отчёт объединяет постановку задачи, данные, разметку, методы предобработки и
сегментации, протокол, метрики, ошибки и воспроизведение. Приложение А содержит
все 12 пар исходного сечения и разметки; приложение Б — показатели каждого
сечения и ссылки на все промежуточные изображения. Это единый учебный проект,
разделённый на задачи, а не набор лабораторных работ.

Отчёт описывает код экспериментов в зафиксированном коммите
`67e83ccc96e7eeddc1f27dbc0c364e621f5f3b7c`. Изменение разметки или методов после
этого коммита не должно молча менять смысл уже выпущенного отчёта.
`frozen_inputs.json` хранит контрольные суммы числовых результатов, изображений
и исходного кода, использованных при сборке документа.

## Сборка редактируемой версии

Команды выполняются из корня репозитория:

```sh
python -m pip install -r walnut01/reports/requirements.txt
# Восстанавливает float32 результаты, не хранящиеся в Git.
python walnut01/tools/run_experiments.py --reuse-selection
python walnut01/reports/build_report.py
```

Измерения времени исходного запуска отдельно сохранены в `timing_snapshot.json`:
новый запуск может иметь другое время и не переписывает этот исторический
снимок. Если исходники, маски или метрики изменились, сборщик отчёта остановится.
Перед обновлением `frozen_inputs.json` нужно проверить текст, числа и ссылки
на версию кода. Для получения отчёта без пересборки используйте сохранённые
PDF/DOCX. Если нужны только иллюстрации, достаточно папки `figures/`.

PDF экспортирован из того же DOCX с сохранением содержания и разбиения на
страницы. Проверены страницы, подписи, таблицы, формулы, номера и ссылки.
